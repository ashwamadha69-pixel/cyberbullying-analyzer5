Trained on real data

The model is trained on the Cyberbullying Classification dataset (Kaggle) — 47,692 real tweets, manually labeled across six balanced categories: age, ethnicity, gender, religion, other cyberbullying, and not cyberbullying.

  • TF-IDF + Logistic Regression, trained in scikit-learn
  • 81.9% accuracy on a held-out 20% test set
  • Model weights exported to run fully client-side — no server, no data leaves your browser
