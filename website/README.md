# Cyberbullying Impact Analyzer

An ML-powered app that classifies online text (tweets/comments) for cyberbullying
content and estimates a **psychological impact/severity score** — combining your
psychology background with applied ML.

---

## 1. Dataset

**Cyberbullying Classification** (Kaggle)
https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification

- 47,000 tweets, 6 balanced classes:
  `age`, `ethnicity`, `gender`, `religion`, `other_cyberbullying`, `not_cyberbullying`
- Columns: `tweet_text`, `cyberbullying_type`

**Already included** in this package at `data/cyberbullying_tweets.csv` (47,692 tweets)
so you don't need to download anything — it's ready to train as-is.

## 3. Setup & Run

### Option A — Static Website (easiest to deploy, no server needed)

A fully client-side version lives in `website/`. The trained model's weights
are embedded directly in `model.js`, and all inference (TF-IDF + logistic
regression + the Impact Score heuristic) runs in the browser with plain
JavaScript — no Python, no backend, nothing to install for whoever views it.

**To run it locally:** just double-click `website/index.html` (or open it in
any browser). That's it.

**To deploy it (pick any one):**
- **Netlify (fastest):** go to https://app.netlify.com/drop and drag the
  `website` folder onto the page. You get a live public URL in seconds.
- **GitHub Pages:** push the `website/` folder contents to a GitHub repo,
  then enable Pages in the repo settings (Settings → Pages → deploy from
  branch → root).
- **Vercel:** `npx vercel` from inside the `website/` folder.

No environment variables, no `.env`, no server to keep running — this is the
right thing to point people to for the demo.

### Option B — Streamlit App (still included)

```bash
pip install -r requirements.txt
```

The model is **already trained** — `model/model.pkl`, `vectorizer.pkl`, and

**Talking point for the demo:** age, ethnicity, and religion are detected very
reliably (96-97%) because they contain distinctive vocabulary. The model is

hard cases where the tweet is rude/sarcastic but not clearly targeting a
protected attribute. This is a known, documented difficulty with this exact
dataset, not a bug in your pipeline — mentioning it shows you understand your
model's behavior rather than just reporting a headline accuracy number.

## 4. How It Works

1. **Text cleaning** — lowercase, strip URLs/mentions/punctuation.
2. **TF-IDF vectorization** — converts text to numeric features (unigrams + bigrams).
3. **Logistic Regression classifier** — predicts one of the 6 categories.
4. **Impact Score (0–100)** — a transparent heuristic combining:
   - category weight (identity-based bullying weighted higher, per literature
     on discriminatory harassment causing greater psychological harm),
   - model confidence,
   - presence of intensifier/absolutist language ("always", "kill", "hate", etc.)

This is the part that makes the project **yours** — it's not just a bullying
detector, it's an *impact estimator*, tying directly to your forensic
psychology interest in cyberbullying's effects on adolescents.
