# Cyberbullying Impact Analyzer

An ML-powered app that classifies online text (tweets/comments) for cyberbullying
content and estimates a **psychological impact/severity score** — combining your
psychology background with applied ML.

---

## 1. Dataset

**Cyberbullying Classification** (Kaggle)
https://www.kaggle.com/datasets/andrewmvd/cyberbullying-classification

- 47,000 tweets, 6 balanced classes:
  `age`, `ethnicity`, `gender`, `religion`, `other_cyberbullying`, `not_cyberbullying`
- Columns: `tweet_text`, `cyberbullying_type`

**Download it and place the CSV here:**
```

```

## 4. How It Works

1. **Text cleaning** — lowercase, strip URLs/mentions/punctuation.
2. **TF-IDF vectorization** — converts text to numeric features (unigrams + bigrams).
3. **Logistic Regression classifier** — predicts one of the 6 categories.
4. **Impact Score (0–100)** — a transparent heuristic combining:
   - category weight (identity-based bullying weighted higher, per literature
     on discriminatory harassment causing greater psychological harm),
   - model confidence,
   - presence of intensifier/absolutist language ("always", "kill", "hate", etc.)

This is the part that makes the project **yours** — it's not just a bullying
detector, it's an *impact estimator*, tying directly to your forensic
psychology interest in cyberbullying's effects on adolescents.
